About This Portal

The Employee Task Manager is a prototype web application developed for the IMS566 individual assignment. It simulates an internal admin portal used to monitor and manage employee tasks.

How to Use This System

  1. Open the Login Page: Enter the provided credentials admin / 1234 and click Login.
  2. View the Dashboard: After logging in, the Dashboard page will display total tasks, completed tasks, pending tasks, a quick task list and a chart summarising the overall distribution.
  3. Check Pending Tasks: Use the navigation bar to open the Pending Tasks page and review tasks that are still open.
  4. Review Completed Tasks: Open the Completed Tasks page to see tasks that have already been finished.
  5. Logout: Use the Logout button in the navigation bar to return to the login screen.
